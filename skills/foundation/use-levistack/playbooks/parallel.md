# Playbook: parallel

Matches "in parallel", "fan out", "try several approaches", "give me three attempts", "split this across agents", "ask a council", or work with independent slices.

| Step | Do | Skill |
|---|---|---|
| 1 Restate | Say the goal, the slices or the shared brief, and how the result will be judged, before spawning anything | — |
| 2 Split the work | Name disjoint file sets per worker. Shared writes serialize. One worker is fine when the work does not split; say why | — |
| 3 Run | Split for different slices, Contest for one brief with several attempts, Council for several judgments of one question | `rumbling` |
| 4 Judge | Weigh every report against the real artifacts and the criteria from step 1 | `evidence` (Judge) |
| 5 Integrate and prove | Merge the accepted work and check the whole | `verify` |
| 6 Close | Unfinished: write the note | `handoff` |

Isolate writers per the `rumbling` contract: non-overlapping files or output folders, or separate worktrees where the project allows them. Each worker owns its files and leaves the others' alone.

**Reply:** the split, what each worker returned, the judge's verdict, what was merged, and the proof.
