# marketing — use case pack

**Status:** `validated`

## When to load

Homepage, landing page, pricing page, feature page, about page.

## Sentence 1 job

State the primary benefit or who this is for — not a mission-statement warmup.

## Section order

1. Headline + subhead (one primary action)
2. Problem → outcome (benefits over feature lists)
3. Proof (numbers, social proof if user gave them)
4. CTA (one verb)

## Default register

`profesional` — simple words; culture from active **language pack** (soft CTA in JP/FR, direct in US EN).

## Techniques

Load [marketing-copy.md](../../techniques/marketing-copy.md) — PAS/AIDA spine, headline formulas, CTA rules, pre-write context checklist.

Then load [locales/](../../techniques/locales/) file for active language when listed in [core.md](../../core.md) § Locale techniques (e.g. [japanese.md](../../techniques/locales/japanese.md#marketing), [indonesia.md](../../techniques/locales/indonesia.md), [mandarin.md](../../techniques/locales/mandarin.md)).

**Inline rules:** clarity over cleverness; benefits over features; one primary CTA; no fabricated proof.
