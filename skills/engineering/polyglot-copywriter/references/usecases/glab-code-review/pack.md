# glab-code-review — use case pack

**Status:** `validated`

## Sentence 1 job

Specific observation or "can we…?" proposal on the diff line.

## Rules

- "Can we…?" not "you should"
- Close with `right?` / `wdyt?` when asking
- Imperatives only for hygiene nits
- **Inline comment** length: 2–5 short sentences; no review essay
- Prefer a GitLab **suggestion** fence when the fix is small

## Default register

`santai` + [simple-prose.md](../../simple-prose.md) (STE-style simple vocabulary)

## When invoked by glab-code-review

- Scope: GitLab MR **draft** inline/general note bodies only — not chat tables, not code identifiers
- Do not add a summary paragraph that repeats other comments
- Full patterns: [review-writing.md](../review-writing.md) § MR Code Review
