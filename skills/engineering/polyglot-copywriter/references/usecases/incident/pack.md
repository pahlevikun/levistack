# incident — use case pack

**Status:** `validated`

## When to load

Outage update, incident comms, status page draft.

## Sentence 1 job

Severity + user impact + current state (not "we apologise for the inconvenience" first).

## Section order

1. Impact and scope
2. Current status / mitigation
3. Next update time or ETA if known
4. Workaround if any

## Default register

`profesional` — `santai` must not hide the warning.

## Techniques

Load [incident-comms.md](../../techniques/incident-comms.md) — severity-first structure.

Load locale technique from [core.md](../../core.md) when language has incident section in [locales/](../../techniques/locales/).

## Do not steal from other formats

- Not marketing tone.
- Not poetic metaphor on data loss.
