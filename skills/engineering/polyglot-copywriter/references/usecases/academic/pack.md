# academic — use case pack

**Status:** `validated`

## When to load

Journal review, paper critique, structured peer feedback.

## Sentence 1 job

Summary judgment or main contribution — not flattery opener.

## Section order

1. Summary of contribution
2. Strengths (specific)
3. Weaknesses / questions (actionable)
4. Recommendation if requested

## Default register

`baku` — no the author slang unless user asked.

## Techniques

Load [academic-writing.md](../../techniques/academic-writing.md) — paper/abstract tone.

Load [locales/japanese.md](../../techniques/locales/japanese.md) or [locales/indonesia.md](../../techniques/locales/indonesia.md) § Academic when language matches.

## Do not steal from other formats

- Not MR review ("can we…?" code style).
- Not marketing superlatives.
