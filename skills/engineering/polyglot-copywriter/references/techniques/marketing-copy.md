# Marketing copy techniques

Marketing copy frameworks (PAS, AIDA, BAB, headline formulas). **English-first examples** — apply phrasing, CTA softness, and proof norms via the active **language pack** and **culture.md**, not by pasting US formulas verbatim.

Load when use case is `marketing`, `ads`, or `social`. For locale-specific marketing (JP キャッチコピー, ID e-com, 文案, …), also load [locales/](locales/) per [core.md](../core.md) § Technique routing.

## Before writing — context checklist

Gather before drafting (ask if missing):

| Area | Questions |
|---|---|
| **Page purpose** | Homepage, landing, pricing, feature, about? One primary action? |
| **Audience** | Who buys? What problem? What objections? What words do *they* use? |
| **Offer** | What changes for them? Differentiator? Proof (numbers, quotes, logos)? |
| **Traffic context** | Ad, email, organic? What do they already know? |

If `.agents/product-marketing.md` or project marketing context exists, read it first.

## Core principles

1. **Clarity over cleverness** — If the reader has to decode the line, you lost them.
2. **Benefits over features** — Features = what it does. Benefits = what that means for the reader.
3. **Specificity over vagueness** — "Cut weekly reporting from 4 hours to 15 minutes" beats "save time on your workflow."
4. **Customer language over company language** — Mirror voice-of-customer from reviews, support, interviews.
5. **One idea per section** — Each block advances one argument; build a logical flow down the page.

## Frameworks (pick one spine)

| Framework | Shape | When |
|---|---|---|
| **PAS** | Problem → Agitate → Solution | Pain-led landing, ads |
| **AIDA** | Attention → Interest → Desire → Action | Full page, email hero |
| **BAB** | Before → After → Bridge | Transformation stories |
| **4 U's** (headlines) | Useful, Urgent, Unique, Ultra-specific | Headline pass only |

**Human Action Model** (hero): current discomfort → better vision → path to action. Run headlines through the **"Now you can"** test: can the reader finish "Now you can ___" from the headline alone?

## Headline formulas

Use as starting points, not fill-in-the-blank:

- `{Outcome} without {pain}` — "Ship releases without weekend deploys"
- `{Category} for {audience}` — "Incident comms for platform teams"
- `Never {bad event} again`
- `{Question about main pain}?`
- `{Number} {people} use {product} to {outcome}` — only with real numbers

**Subhead:** expands headline, adds specificity, 1–2 sentences max.

## CTA rules

| Weak (avoid) | Strong (prefer) |
|---|---|
| Submit, Sign Up, Learn More, Click Here, Get Started | Start free trial, Get [specific thing], See [product] in action |

**Formula:** [Action verb] + [what they get] + [qualifier if needed]

One primary CTA per section. Repeat at close with value recap, not a new pitch.

## Page structure (marketing use case)

Aligns with [marketing/pack.md](../usecases/marketing/pack.md):

1. Headline + subhead + primary CTA
2. Problem / empathy (you understand their situation)
3. Solution / benefits (3–5 outcomes, not feature dumps)
4. How it works (3–4 steps — reduce perceived complexity)
5. Proof (only what user supplied)
6. Objections / FAQ if needed
7. Final CTA + risk reversal if real (guarantee, trial)

**Ads / social:** hook → one proof fact → CTA. See [ads/pack.md](../usecases/ads/pack.md) and [social/pack.md](../usecases/social/pack.md).

## Style pass (with core + noslop)

- Simple over complex; active over passive; confident over qualified
- No fabricated stats, testimonials, or logos
- No exclamation points in B2B unless brand demands
- Jargon only if the audience uses it daily

## Quality check (30 seconds)

- [ ] Sentence 1 states benefit or audience, not mission warmup
- [ ] Every claim has source or is honestly vague
- [ ] One primary action per page/section
- [ ] CTA says what they get
- [ ] Language pack applied (register, culture, transcreation where needed)
