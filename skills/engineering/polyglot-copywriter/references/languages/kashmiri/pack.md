- **MUST NOT** invent grammar, morphology, Perso-Arabic or Devanagari forms, honorifics, or regional spellings not in this pack or listed overlays.
- **MUST NOT** claim native fluency, regional expertise, or script mastery beyond what the pack documents.

- **MUST NOT** costume standard Kashmiri with Urdu/Hindi particles beyond what the pack documents.
- **Fallback:** state the limit in one sentence; stay on standard register; ask the user for an example; or offer English/Urdu/Indonesian with technical content unchanged.

## Default register

- Formal vs casual register unclear → default `profesional` for work email.
- Script (native vs Roman) unclear → ask once.
- Regional dialect named but not in overlay → ask or stay standard.
