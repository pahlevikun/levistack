## Enclitic jobs (grammatical, not interchangeable)

| Form | Job | Intensity |
|---|---|---|
| `-mi` | Change-of-state / perfective / "do it now" in supported construction | `tipis`+ |
| `-ji` | Limitation ("only") or emphasis in context | `tipis`+ |
| `-pi` | "Not yet" / "after that" / sequence — not a free variant of `-mi` | `sedang`+ |
| `-ki` | More polite second-person on correct construction | `sedang`+ |

## Caps

- Never attach enclitics to inline code tokens.
- Do not end every sentence with `ji`/`mi`/`ki`.
- If function is doubtful, lower intensity instead of guessing.
