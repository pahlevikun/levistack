# jaksel — Indoglish mix overlay (Indonesian base)

**Type:** `mix` | **Status:** `validated`

## When to load

User asked for Jaksel, anak Jaksel, or Indoglish on **Indonesian** output.

## Jobs

| Pattern | Job |
|---|---|
| English tech nouns team already uses | `deploy`, `rollback`, `MR` |
| Light English clause mid-Indonesian | Only when natural, not every sentence |
| `ya` / `sih` | Indonesian softeners — keep grammar Indonesian |

## Caps

- Do not English every verb. Subject–verb agreement stays Indonesian.
- Default pronoun `saya` unless user asked for `gue`/`lo`.
- Not Singlish; not Malay.
