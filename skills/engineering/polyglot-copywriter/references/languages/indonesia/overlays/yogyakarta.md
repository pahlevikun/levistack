# yogyakarta — Yogyakarta overlay

**Type:** `regional` | **Status:** `validated`

## When to load

`language: indonesia` + `regional_voice: yogyakarta` (Jogja colour). Related to Solo but not identical.

## Jobs

| Form | Job | Intensity |
|---|---|---|
| `je` | Emphasis / attitude on the info | `sedang`+ |
| `gek` | Temporal construction only when user/modelled it | do not guess |
| `lha`, `kok`, `to`/`tho`, `mbok` | Pragmatic particles | one job each |
| `dhisik`, `maneh`, `durung`, `wis`, `piye`, `nggih` | Jogja rhythm | per speech level |
| `Mas`/`Mbak` | Contextual address | not automatic |

## Caps

- Not the same as `jawa` + `krama` — Jogja also has casual registers.
- Do not import Solo markers (`ki`/`rik`) as Jogja default.
- No repeated `je` without emphasis function.
- No mixing Yogya warmth with Surabaya bluntness in one draft.
