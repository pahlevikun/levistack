# Bahasa Indonesia — language pack

**Status:** `validated`. Load when `language: indonesia`.

## Load map

| User signal | Load |
|---|---|
| Everyday writing | `pack.md` + `registers.md` |
| Transcreation, pronouns, directness | also `culture.md` |
| City style or Jaksel mix | also **one** overlay from `overlays/` |

## Honesty

Default the author Indonesian is **work chat**: `saya` + `mas`/`kak`, simple words, impact-first. City overlays add colour at `tipis`/`sedang`; do not require `gue`/`lo` for Jakarta.

## Default register

`santai` — **not** full gaul slang. `profesional` and `baku` on request. EYD / formal spelling only on `baku`.

## the author fingerprint

Load [voice-fingerprint.md](../../voice-fingerprint.md) when writing as the author in Indonesian.

## When to ask

- `Sunda kasar` without loma/cohag → ask (see [speech-levels for sunda](../sunda/speech-levels.md) if `language: sunda`).
- Unknown city or invented place → fall back to `regional_voice: netral`.
