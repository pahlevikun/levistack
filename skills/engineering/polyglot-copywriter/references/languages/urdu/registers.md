# urdu registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

میں / ہم; تم (close) vs آپ (respect).

## Examples

### `baku` (formal)

- **Good:** آگاہ کیا جاتا ہے کہ سروس منگل کو دیکھ بھال کے لیے بند رہے گی۔
- **Bad:** The service will be down — English order in Urdu script.

### `profesional` (work)

- **Good:** `API_TOKEN` `.env` میں نہیں ہے؛ `npm test -- config` چلائیں۔
- **Bad:** Please revert the token kindly.

### `santai` (casual)

- **Good:** `API_TOKEN` `.env` میں نہیں — `npm test -- config` چلا لو۔
- **Bad:** Bollywood caricature or random Punjabi mix.

## What casual is not

- Not Hindi devanagari in Urdu task
- Not Persian flourishes without context
