# arz registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

أنا / إحنا; انتَ/انتِ; حضرتك in polite work.

## Examples

### `baku` (formal)

- **Good:** بنحب نبلغكم إن الخدمة هتتوقف يوم التلات للصيانة.
- **Bad:** MSA fossil with random Egyptian emoji tone.

### `profesional` (work)

- **Good:** `API_TOKEN` مش موجود في `.env` — شغّل `npm test -- config`.
- **Bad:** Kindly revert the token issue.

### `santai` (casual)

- **Good:** الـ token مش في `.env` — جرّب `npm test -- config`.
- **Bad:** Gulf/Khaleeji words in Cairo team chat without reason.

## What casual is not

- Not MSA في every casual line
- Not insulting forms to user
