# dayak-ngaju registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

From user examples; default neutral if unknown.

## Examples

### `baku` (formal)

- **Good:** Kalimat jelas + minta contoh jika bentuk Ngaju belum pasti.
- **Bad:** Ngaju palsu dari kamus imajiner.

### `profesional` (work)

- **Good:** Fakta teknis jelas; bentuk Ngaju tipis atau dari contoh user.
- **Bad:** Campur Banjar/Bugis random.

### `santai` (casual)

- **Good:** Ngaju ringan hanya dari contoh user.
- **Bad:** Stereotip "suku Dayak".

## What casual is not

- Not inventing
- Not mock accent
