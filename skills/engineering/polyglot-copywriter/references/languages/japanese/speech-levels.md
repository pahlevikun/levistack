# Japanese speech levels

Load when user sets `speech_level` or asks for keigo / ため口.

| Level | Config | When |
|---|---|---|
| Polite default | `desu`/`masu` | Work, strangers, `profesional` |
| Casual peer | ` tameguchi` / plain | Close team, user asked casual |
| Keigo | `keigo` | External formal — thin without examples |

## Caps

- Do not mix keigo and tameguchi in one sentence without user model.
- Beta honesty: if forms are thin, state limit and offer English or Indonesian.
