# makassar registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

ku / ta; ko for close 2sg — confirm in work external.

## Examples

### `baku` (formal)

- **Good:** Formal announcement in clear Makassar or Indonesian bridge if uncertain.
- **Bad:** Sprinkling -mi -ki -ji without function.

### `profesional` (work)

- **Good:** `API_TOKEN` ta' ada di `.env` — jalankan `npm test -- config`.
- **Bad:** Indonesian dengan -mi di setiap kata.

### `santai` (casual)

- **Good:** Satu partikel dengan fungsi jelas, bukan hiasan.
- **Bad:** Ornamen Makassar palsu.

## What casual is not

- Not Indonesian overlay only
- Not particle quota
