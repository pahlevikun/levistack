# minangkabau registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

ambo / awak / sanak — register-dependent; default polite work forms.

## Examples

### `baku` (formal)

- **Good:** Pengumuman resmi dengan bentuk hormat Minang yang jelas.
- **Bad:** Campur Jakarta gaul.

### `profesional` (work)

- **Good:** `API_TOKEN` indak ado di `.env` — jalankan `npm test -- config`.
- **Bad:** Indonesian dengan -lah random.

### `santai` (casual)

- **Good:** Minang ringan; partikel dengan fungsi.
- **Bad:** Kental tanpa varietas.

## What casual is not

- Not gue/lo
- Not kental without variety
