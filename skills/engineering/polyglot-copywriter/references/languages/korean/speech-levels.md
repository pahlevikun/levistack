# Korean speech levels (존댓말 / 반말)

| Level | Config | When |
|---|---|---|
| Polite | `jondaetmal` | Default work, strangers |
| Casual | `banmal` | Close peers only — ask if unclear |
| Formal written | `haeyo`/`hapnida` | Docs, external |

## Caps

- Never drop to banmal without closeness signal.
- Beta: thin forms → honesty cap at `sedang`.
