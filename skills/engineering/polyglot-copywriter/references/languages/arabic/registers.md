# arabic registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

MSA: أنا / نحن for ownership; أنتَ/أنتِ or حضرتك in formal work. Dialect packs override pronouns.

## Examples

### `baku` (formal)

- **Good:** نود إبلاغكم بأن الخدمة ستتوقف للصيانة يوم الثلاثاء.
- **Bad:** Hey team, the service will be down Tuesday — translated word order.

### `profesional` (work)

- **Good:** السبب أن `API_TOKEN` غير موجود في `.env`. شغّل `npm test -- config`.
- **Bad:** Kindly revert regarding the token issue.

### `santai` (casual)

- **Good:** الـ token مش موجود في `.env` — جرّب `npm test -- config`.
- **Bad:** Slang soup mixing dialect markers from three countries.

## What casual is not

- Not random dialect spelling without an active overlay
- Not insulting forms in incident or review text
