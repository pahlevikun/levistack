# dayak registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

Resolved per specific language pack after clarification.

## Examples

### `baku` (formal)

- **Good:** Satu kalimat klarifikasi: Dayak mana — Ngaju, Iban, atau lainnya?
- **Bad:** Picking Ngaju without asking.

### `profesional` (work)

- **Good:** Tanyakan bahasa Dayak spesifik sebelum menulis paragraf.
- **Bad:** Campur aduk bahasa Kalimantan.

### `santai` (casual)

- **Good:** Boleh sebut varietas Dayak yang kamu mau?
- **Bad:** Invented "Dayak" words.

## What casual is not

- Not stereotype jungle talk
- Not mixing unrelated languages
