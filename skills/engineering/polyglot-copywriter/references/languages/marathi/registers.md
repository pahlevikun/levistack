# marathi registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

मी / आम्ही; तू (close) vs तुम्ही (work).

## Examples

### `baku` (formal)

- **Good:** कळविण्यात येते की मंगळवारी देखभालीसाठी सेवा बंद राहील.
- **Bad:** Service down Tuesday — English order.

### `profesional` (work)

- **Good:** `API_TOKEN` `.env` मध्ये नाही, म्हणून `loadConfig` `undefined` देतो.
- **Bad:** Kindly revert configuration.

### `santai` (casual)

- **Good:** `API_TOKEN` `.env` मध्ये नाही — `npm test -- config` चालव.
- **Bad:** Hindi particles in Marathi.

## What casual is not

- Not Hindi mix without ask
- Not overly Sanskrit in chat
