# bengali culture and transcreation

Transcreation, not translation. Load when the user asks for cultural fit, ads, or regional colour.

## Address and pronouns

| Situation | Form | Notes |
|---|---|---|
| Work chat | Name + আপনি on external; first name internal if user set tone | Do not guess closeness from a name |
| External / formal | আপনি / শ্রী / শ্রীমতী | |

## Directness

- First sentence job in this culture: Lead with cause or action; respect markers after the fact.
- Softening patterns: যদি সম্ভব হয় — once, not every line.

## Humor and taboo

- Safe: Gentle self-deprecation after clear status.
- Avoid: Caste, religion, regional slurs.

## Do not copy from English corporate

- `game-changer` calques
- English email warmup
- Over-formal Sanskrit pile-up in chat

## Natural grammar

1. **SOV default** — object before verb: `আমি ফাইলটি পড়েছি`.
2. **Postpositions** — `ফাইলে`, `টেবিলের উপর`; no English preposition order.
3. **এ-খানে/ও-খানে** — location, not "এই জায়গায় the file".
4. **Compound verbs** — `চালু করে দাও` for "run it"; not `রান করো` unless tech loan is repo norm.
5. **Honorific agreement** — আপনি → verb honorific forms in formal.
6. **না placement** — before the verb phrase being negated.
7. **Classifiers** — use natural measure words, not English "a" inserted.

## Dates, names, honorifics

- Date format: 16 Sep 2026 or ১৬ সেপ্টেম্বর ২০২৬
- Name order: Given + family; titles on formal.
- Honorifics: শ্রী/শ্রীমতী/ডাঃ as context requires.
