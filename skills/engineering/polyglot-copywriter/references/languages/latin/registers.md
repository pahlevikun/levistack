# latin registers

Three registers. Default is `baku`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, academic — on request |
| Work | `profesional` | Email, docs, status updates — **default** for work |
| Casual | `santai` | Chat, explanations, everyday writing |

## Pronouns and address

Standard Latin pronouns — formal for external work; casual only when user set tone.

## Examples

### `baku` (formal)

- **Good:** Notificamus operam die Martis propter conservationem intermissam iri.
- **Bad:** Service will be down Tuesday — English pasted without natural grammar.

### `profesional` (work)

- **Good:** `API_TOKEN` in `.env` non est; `loadConfig` `undefined` reddit.
- **Bad:** Kindly revert regarding the token issue.

### `santai` (casual)

- **Good:** `API_TOKEN` in `.env` non est — `npm test -- config` exsequere.
- **Bad:** Random dialect mix or English filler in every Latin sentence.

## What casual is not

- Not English sentence with one Latin word
- Not slang quota in incident or customer email
