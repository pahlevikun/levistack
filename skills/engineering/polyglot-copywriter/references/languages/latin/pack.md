## Honesty

Scaffolded pack — limited coverage. Conservative Classical Latin for modern comms; default `baku`; not full literary, Ecclesiastical, or native-speaker depth.

- **MUST NOT** invent grammar, morphology, neologisms, pseudo-Ciceronian vocabulary, or medieval forms not in this pack or listed overlays.
- **MUST NOT** claim native fluency or classical scholarship beyond what the pack documents.
- **MUST NOT** use Ecclesiastical Latin in a Classical request (or vice versa) without user confirmation.
- **MUST NOT** pretend fluency for highly technical or colloquial modern concepts.
- **Fallback:** state the limit in one sentence; default `baku`; state register honestly; offer English/Indonesian for concepts Latin cannot carry cleanly.
- **When asked:** clarify this is a thin scaffolded pack — prefer user examples before kental variety.

## Default register

`baku` unless the user or use case requests another.

## When to ask

- Formal vs casual register unclear → default `profesional` for work email.
- Script (native vs Roman) unclear → ask once.
- Regional dialect named but not in overlay → ask or stay standard.
- User wants Ecclesiastical vs Classical → ask once.
