# Malay — language pack

**Status:** `validated`. Malaysian Malay is **not** Indonesian and **not** Singlish.

## Load map

| User signal | Load |
|---|---|
| Everyday writing | `pack.md` + `registers.md` |
| Culture, spelling, address | also `culture.md` |
| Manglish mix | overlay `manglish` on explicit ask |

## Honesty

Cap `intensity` at `sedang` without user examples or named variety. Do not collapse into `indonesia` or `singlish`.

## Default register

`santai` for chat; `profesional` for work email.

## Lexicon anchors (not a slang list)

- Negation: `tak` (not Indonesian `nggak`/`tidak` default in casual — use `tak` in Malay casual)
- You: `awak` / `kamu` (context-dependent)
- Many: `ramai` (not `banyak` as default casual)
- Spelling: Malaysian conventions (`pejabat`, `faktori` where distinct)

## When to ask

- Manglish vs pure Malay vs English → one clarifying question if user said only "Malay".
- Do not default to Indonesian particles (`sih`, `dong`) or Jakarta `gue`/`lo`.
