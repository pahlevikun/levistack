# Malay culture and transcreation

## Address and pronouns

| Situation | Form | Notes |
|---|---|---|
| Work chat | `saya` + name or `awak` | Not `mas`/`kak` unless team already uses it in MY context |
| Formal | `Saya` + title | |

## Directness

- Malay work prose can be slightly softer than US English; still put the ask early.
- Do not import Indonesian corporate calques.

## Do not copy from Indonesian

- Default `nggak`, `banget`, `gue`/`lo`, Jakarta particles as Malay default
- Do not treat Malay as "Indonesian with different spelling" only — check `tak`, `awak`, `ramai`

## Manglish

- Load `overlays/manglish.md` only on explicit Manglish request — distinct from Singlish.
