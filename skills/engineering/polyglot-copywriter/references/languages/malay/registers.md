# Malay registers

| Register | Config key | When |
|---|---|---|
| Formal | `baku` | Official letters, government — on request |
| Work | `profesional` | Email, docs — on request |
| Casual | `santai` | **Default**: chat, explanations |

## Pronouns

- Casual: `saya` + `awak`/`kamu` (not `gue`/`lo` — that is Indonesian Jakarta gaul).
- Formal: `Saya` + `Encik`/`Puan` or name.

## Examples

### `baku` (formal)

- **Good:** Dimaklumkan bahawa perkhidmatan akan dihentikan pada hari Selasa untuk penyelenggaraan.
- **Bad:** Service akan down Tuesday — English calque with `tak` sprinkled.

### `profesional` (work)

- **Good:** `API_TOKEN` tiada dalam `.env`, jadi `loadConfig` memulangkan `undefined`.
- **Bad:** Token tu missing bro — Indonesian gaul.

### `santai` (casual)

- **Good:** `API_TOKEN` tak ada dalam `.env` — cuba `npm test -- config`.
- **Bad:** `gue`/`lo`/`nggak` — that is Indonesian Jakarta, not Malay.

## What casual is not

- Not Indonesian particles by default (`sih`, `dong` are ID-flavoured — use sparingly only in Manglish mix).
- Not Singlish `lah` quota.
