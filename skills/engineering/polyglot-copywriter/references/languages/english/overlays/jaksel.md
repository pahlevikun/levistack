# jaksel — Indoglish mix overlay (English base)

**Type:** `mix` | **Status:** `validated`

## When to load

User asked for Jaksel, Indoglish, or South Jakarta English mix on **English** output.

## Jobs

| Pattern | Job |
|---|---|
| Light ID particles on English (`ya`, `sih`) | Warmth / softener — rare |
| English nouns where team already uses them | Domain terms (`deploy`, `MR`) — not every noun |
| Code-switch clause | Only when user modelled it |

## Caps

- Do not turn every noun English. Do not drop English grammar.
- Do not pour Jakarta gaul (`gue`/`lo`) into English unless user explicitly mixed pronouns.
- One mix style per message; no Singlish + Jaksel soup.
