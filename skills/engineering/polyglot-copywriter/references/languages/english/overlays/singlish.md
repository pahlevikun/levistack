# singlish — Singapore English mix overlay

**Type:** `mix` | **Status:** `validated`

## When to load

User asked for Singlish, Singapore English, or `regional_voice: singlish` on English output.

## Particle jobs (no lah spam)

| Particle | Job | When to skip |
|---|---|---|
| `lah` | Softener or emphasis at clause end | If sentence already clear |
| `leh` | Seek agreement / surprise | Not every question |
| `lor` | Resignation / "that's how it is" | Not as filler |
| `mah` | Obviousness | Rare |
| `hor` | Check shared understanding | One per message max at `sedang` |

## Other forms

- `can or not?` — yes/no feasibility check
- `got` / `already` — emphasis OK at `sedang`+

## Caps

- **No lah quota.** If you cannot state the particle's job, drop it.
- US spelling unless user asked otherwise. Simple vocab.
- No mocking phonetic spelling.
