# punjabi culture and transcreation

Transcreation, not translation. Load when the user asks for cultural fit, ads, or regional colour.

## Address and pronouns

| Situation | Form | Notes |
|---|---|---|
| Work email | ਤੁਸੀਂ + respectful verb | Default for India Gurmukhi |
| Peer chat | ਤੂੰ possible | Only when user already casual |
| Pakistan | Light overlay — ask script preference | Shahmukhi not fully documented |

## Directness

- Lead with problem or benefit; details follow.
- `ਕਿਰਪਾ ਕਰਕੇ` once per request.

## Humor and taboo

- Safe: dry after facts.
- Avoid: religion/politics stereotypes, mock rural accent.

## Do not copy from English corporate

- `leverage` calques → direct Punjabi verb
- Long passive English → active Punjabi

## Natural grammar

1. **SOV tendency** — verb placement natural to Punjabi, not English order pasted.
2. **Gender agreement** — verb/adjective with subject gender where applicable.
3. **Postpositions** — ਨੂੰ, ਵਿੱਚ, ਤੋਂ accurately.
4. **Gurmukhi spelling** — standard forms; no invented dialect spellings.
5. **Respectful ਤੁਸੀਂ** — default in B2B and incident comms.
6. **Code tokens** — keep `API_TOKEN`, paths literal.
7. **Numbers** — digits for metrics in work prose.

## Dates, names, honorifics

- Date format: 16-09-2026
- Honorifics: ਸ਼੍ਰੀ / ਸ਼੍ਰੀਮਤੀ in formal external when appropriate
