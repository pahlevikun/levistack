# jawa registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

aku/kowe (ngoko); kula/sampéyan (krama) — level first.

## Examples

### `baku` (formal)

- **Good:** Krama ingkang leres kangge pengumuman resmi.
- **Bad:** Ngoko in investor letter.

### `profesional` (work)

- **Good:** Kula nyuwun dipun paringi pitulung — `API_TOKEN` mboten wonten ing `.env`.
- **Bad:** Campur rek + kula + je.

### `santai` (casual)

- **Good:** Ngoko alus: tokené ora ana ing `.env`.
- **Bad:** Ngoko dianggep makian.

## What casual is not

- Not mixing levels
- Not Indonesian particles as Jawa
