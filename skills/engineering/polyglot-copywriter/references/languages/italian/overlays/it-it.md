# it-it — Italy Italian

**Type:** `regional` | **Status:** `validated`

## When to load

`language: italian` + `regional_voice: it-it`. Standard Italy Italian — default overlay.

## Particle and grammar jobs

| Form | Pragmatic job | Intensity |
|---|---|---|
| `Lei` | Formal work default | `tipis+` |
| `per favore` | Softener on requests | `tipis+` |
| `quindi` | Therefore in explanation | `tipis+` |
| `allora` | Transition / acknowledgment | `tipis+` |

## Examples (bug explanation)

- `API_TOKEN` manca in `.env`, quindi `loadConfig` restituisce `undefined`. Eseguire `npm test -- config`, per favore.

## Caps

- Default Italy overlay; no Swiss or regional dialect markers.

## What NOT to mix

- Swiss `grüezi` lexicon or `ss`/`ß` confusion from de-ch.

## Forbidden caricature

- Exaggerated hand-gesture stage directions or comic accent spelling.
