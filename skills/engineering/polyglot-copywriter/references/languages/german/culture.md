# german culture and transcreation

Transcreation, not translation. Load when the user asks for cultural fit, ads, or regional colour.

## Address and pronouns

| Situation | Form | Notes |
|---|---|---|
| Work chat | Sie + surname or first name per company culture | Do not guess closeness from a name |
| External / formal | Sie + Herr/Frau + surname | |

## Directness

- First sentence job in this culture: Lead with Nutzen or problem; details follow.
- Softening patterns: Könnten Sie bitte — once.

## Humor and taboo

- Safe: Dry after facts.
- Avoid: Nazi references, dialect mockery.

## Do not copy from English corporate

- `circle back` → `wir melden uns`
- `leverage` calques

## Natural grammar

1. **V2 in main clauses** — verb second after fronted object.
2. **Subordinate verb-final** — `..., weil das Token fehlt`.
3. **Capitalize nouns** — Token stays code; common nouns capitalized.
4. **Compound nouns** — `API-Token` not `Token von API` if naturalized.
5. **Sie agreement** — verb and possessives formal.
6. **nicht placement** — before what it negates.
7. **Imperative Sie** — `Bitte starten Sie` in work email.

## Dates, names, honorifics

- Date format: 16.09.2026 or Dienstag, 16. September 2026
- Name order: Given + family
- Honorifics: Herr/Frau + surname
