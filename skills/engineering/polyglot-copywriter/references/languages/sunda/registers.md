# sunda registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

abdi/saéndén (polite); manéh/érang by level.

## Examples

### `baku` (formal)

- **Good:** Basa hormat keur surat resmi.
- **Bad:** Cohag keur klien éksternal tanpa sinyal.

### `profesional` (work)

- **Good:** `API_TOKEN` teu aya di `.env` — jalankan `npm test -- config`.
- **Bad:** Campur Jawa rek.

### `santai` (casual)

- **Good:** Loma: tokenna teu aya di `.env`.
- **Bad:** Ngina ka pamaké.

## What casual is not

- Not cohag without ask
- Not Jawa mix
