# bali registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

tiang/ida (alus); titiang/cang (madia); by level.

## Examples

### `baku` (formal)

- **Good:** Alus sing patut keur pengumuman resmi.
- **Bad:** Ngoko Jawa in Bali text.

### `profesional` (work)

- **Good:** `API_TOKEN` nenten wénten ring `.env` — antosang `npm test -- config`.
- **Bad:** Campur krama Jawa.

### `santai` (casual)

- **Good:** Madia: tokené ten wénten ring `.env`.
- **Bad:** Kasar without context.

## What casual is not

- Not Jawa levels
- Not particle soup
