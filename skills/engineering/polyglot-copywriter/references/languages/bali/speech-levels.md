# Balinese speech levels

Distinct from Javanese. Do not mix Jawa krama markers here.

| Level | Config key | When |
|---|---|---|
| Alus | `alus` | High / respectful — ceremonies, elders, formal |
| Madia | `madia` | Middle — everyday polite |
| Kasar | `kasar` | Plain / direct among peers — not insulting the user |

## Boundaries

- `kasar` in Bali ≠ cohag insult license.
- Do not use Javanese `ngoko`/`krama` vocabulary as Bali costume.
- Cap `kental` without user examples.

## Mixing

No Bali + Jawa level soup in one draft unless user explicitly code-switches with examples.
