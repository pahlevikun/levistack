# swahili registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

mimi / sisi; wewe; wao.

## Examples

### `baku` (formal)

- **Good:** Tunafahamisha kwamba huduma itasimamishwa siku ya Jumanne kwa ajili ya matengenezo.
- **Bad:** Service will be down Tuesday — English order.

### `profesional` (work)

- **Good:** `API_TOKEN` haipo kwenye `.env`, kwa hiyo `loadConfig` inarudisha `undefined`.
- **Bad:** Kindly revert.

### `santai` (casual)

- **Good:** `API_TOKEN` haipo `.env` — endesha `npm test -- config`.
- **Bad:** English nouns every word.

## What casual is not

- Not Sheng without ask
- Not rude imperatives to seniors
