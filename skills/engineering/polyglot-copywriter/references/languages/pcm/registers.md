# pcm registers

Three registers. Default is `santai`. Casual is **not** automatically slang.

| Register | Config key | When |
|---|---|---|
| Formal / careful | `baku` | Official letters, legal, investor — on request |
| Work | `profesional` | Email, docs, LinkedIn — on request |
| Casual | `santai` | **Default**: chat, explanations, everyday writing |

## Pronouns and address

I / we; you; dem for they.

## Examples

### `baku` (formal)

- **Good:** We wan inform una say service go stop for maintenance on Tuesday.
- **Bad:** Kindly revert regarding the maintenance window.

### `profesional` (work)

- **Good:** `API_TOKEN` no dey for `.env`, so `loadConfig` dey return `undefined`.
- **Bad:** The API_TOKEN is not present in the environment file — stiff translation.

### `santai` (casual)

- **Good:** `API_TOKEN` no dey `.env` — run `npm test -- config`.
- **Bad:** Mocking tone or fake Jamaican mix.

## What casual is not

- Not "comedy African accent" spelling
- Not English corporate in PCM announcement
