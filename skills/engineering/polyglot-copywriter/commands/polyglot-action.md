Use the `polyglot-copywriter` skill with the `action-first` use case on: $ARGUMENTS

Load `references/usecases/action-first/pack.md` and `references/simple-prose.md`.
Put an action the reader can do now in the first line. Number the steps, use the
fewest that work, and end on one next step that takes about two minutes. Give every
time estimate a basis, or say it is unknown. State errors as place, cause and fix.
Leave out openers, recaps and closers.

If I wrote "on" or "adhd mode", keep this shape on every reply in the session until I
say "stop adhd mode" or "normal mode". Confirm the stop in one line, then go back to
the default style. If I asked for an explanation, explain fully with headings and
still start with the action when there is one. Ask before anything destructive.

No em dash, en dash, or semicolon in the final text. Keep every fact, command and path.
