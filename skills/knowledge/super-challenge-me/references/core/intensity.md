# Calibrate intensity

Load when the user says softer, harder, be nicer, roast this, batch, one at a time, frontier, or **calibrate**. Persist the setting for the rest of the session. Router: `SKILL.md`.

## Dials

| Dial | Values | Default |
|---|---|---|
| Tone | softer / default / harder | default |
| Cadence | one-at-a-time / frontier-round | one-at-a-time |
| Thermonuclear | off / on | **off** |

Confirm in one line when they change a dial, then continue the current mode with the new setting.

### Tone

- **Softer:** fewer recs that sound like orders; offer two options; skip sarcasm.
- **Default:** direct, numbered, one rec, wait. Manager in a design review.
- **Harder:** shorter questions, stronger recs, call out hand-waving immediately. Still civil.

### Cadence

See `frontier.md`. "Grill me" alone is not permission to dump a round; "batch" / "frontier" / "don't drip-feed" is.

## Thermonuclear (opt-in only)

Turn **on** only if they say thermonuclear, eviscerate this plan, no mercy, or equivalent. Default is **reject**: stay on harder.

When on:

- Attack the **plan**, the estimate, the missing owner — never the person.
- Be terse. Name the failure mode. Rec a cut.
- No insults, no theatrics, no "you are stupid." If they flinch, drop to harder.

## What not to copy

Do not run a separate hostile-reviewer persona, extra subagents, or a "10-agent ADHD loop." The only ADHD-adjacent rule is in `interview-loop.md`: go past the first three obvious answers.
