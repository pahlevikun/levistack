# Research synthesis

Captured while merging prior catalog grilling skills with public challenge and brainstorming patterns. Not a verbatim import.

## Shared themes

1. **Design-tree grilling.** Recurse every undecided point; numbered question + recommended answer; wait; user owns decisions.
2. **Do not ask facts.** Search the tree and docs; ask only trade-offs.
3. **Cadence is a dial.** One-at-a-time vs a frontier round of independent questions.
4. **Blunt scope check.** Estimates hide work; the real product is often larger than the pitch.
5. **Design before implementation.** Brainstorm to a shared spec; new vs existing product is a track, not a second skill.
6. **State that survives sessions.** A compact markdown map beats chat archaeology.
7. **Past the first three.** Force one non-obvious option, then choose. Do not industrialize this into agent swarms.
8. **Domain docs, not verticals.** Glossary/ADR grilling generalizes; narrow vertical packs stay out. Store/clone harnesses stay out; keep the interview method.

## What levistack keeps from prior grilling skills

- `CONTEXT.md` / `CONTEXT-MAP.md`, glossary alignment, precision sharpening, scenario probes.
- ADR only when hard-to-reverse, surprising, and a real trade-off.
- Inline doc updates as names crystallize.
- Pair with `super-codebase-learner` **diagnose** for in-place deepening.

## Gaps this skill fills

- One router for grill / grill-docs / challenge / brainstorm / decision-map / calibrate.
- Explicit handoffs: learner (facts), tech-blueprint (target stack), writing-plans / super-refactor (execution), create-jira-story (tickets).
- Intensity including opt-in thermonuclear that still forbids attacking the person.

## Out of scope

- Writing the machine-readable implementation-plan file (thin pointer to `writing-plans`).
- Subagent `do` / `make-plan` orchestration (`handoff` after a plan exists).
- A ZH-CN (or any) language pack; format is language-agnostic.
- Proprietary interview stores, clone scripts, or diagram-skill takeover.
