# Domain: design-ui

Load after the mode when the subject is UI, UX flow, visual design, or a screen that is the product.

## Artifacts

Mock, flow list, component sketch, copy-on-screen treated as UI spec.

## Lenses

- Job the screen does in one sentence
- Empty, error, loading, permission-denied — not only the happy path
- What is primary vs decorative; what to remove
- Platform constraints you already know (repo components, not a new design system)
- Accessibility as decisions (focus order, names), not a lecture

## Do not

- Take over as a diagram or design-system skill.
- Invent a component library. Use what the repo has.
