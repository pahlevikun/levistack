# Rewrite the report

Rewrite only the pending answer. Do not change the underlying artifact or invent a missing check.

1. Put the observed outcome in the first sentence.
2. Keep the concrete artifact, source, command, count, and limitation that each material claim needs.
3. Separate verified behavior from inference and unverified work. If the evidence is missing and can still be checked, run `verify` before making the claim; otherwise narrow the claim.
4. Remove process narration, filler, unsupported praise, and follow-up suggestions unrelated to the task.

Return the rewritten answer alone unless the user asked for an explanation of the edit.
