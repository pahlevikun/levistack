# Council on one question

Use Council for a decision where independent investigation can expose different risks, assumptions, or evidence. Agents are read-only by default.

1. Write the decision as one sentence. List the real options, the artifact to inspect, and the criteria that will decide it. Give every seat the same evidence pack.
2. Choose different available models before adding perspective diversity. Then assign non-overlapping lenses such as correctness, delivery cost, and failure modes. If models cannot differ, state that limit and use the distinct lenses.
3. Ask each seat for source paths and observations, competing options, risks, likely implementation and verification cost, a recommendation, and unknowns. Dispatch together. Do not share one seat's result with another during the independent pass.
4. When all reports arrive, check the cited evidence yourself. Compare claims by support and relevance, not vote count. Investigate conflicts before choosing. A majority of unsupported opinions does not beat one reproducible finding.
5. Write one recommendation with the winning criteria, the strongest contrary evidence, confidence, and the next concrete action. Hand that decision record and all seat reports to the shared `evidence` Judge gate in [SKILL.md](../SKILL.md).

For an existing code diff whose purpose is to find blind spots and resolve every finding with the author, route directly to `second-opinion` instead.
