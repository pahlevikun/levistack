# Check a document with a cold reader

Use this optional pass for an important handover, tutorial or proposal whose
reader lacks the authoring conversation. It is a comprehension check, not source
verification and not a mandatory interview for every small edit.

1. Name the reader and three to six tasks or questions the document must answer.
   Derive questions from its purpose, rather than trivia about its wording.
2. Freeze the document revision and the questions. Give an authorized independent
   reader only the document, its declared audience and the questions. Withhold the
   conversation and expected answers. If no independent reader is available, make
   a sequential cold-read pass and disclose the loss of independence.
3. Record each answer with the section that supports it, or mark it unanswered,
   ambiguous or dependent on outside knowledge. A fluent guess is not a pass.
4. Check the answers against the actual sources yourself. Reader agreement cannot
   validate a false claim, unsafe command or missing prerequisite.
5. Fix material gaps within the requested document scope. Repeat only failed
   questions on the new revision and retain the initial result so improvement is
   visible. Stop when reader tasks are answerable or the remaining gaps are explicit.

Return a short table: reader task, document anchor, observed answer/gap, correction,
remaining limit. Do not claim fresh-agent testing when only the author reviewed it.
For file parsing, reconstruction or export, use file-toolkit rather than rewriting
format conversion scripts inside the documentation task.
