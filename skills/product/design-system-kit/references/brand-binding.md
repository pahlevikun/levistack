# Apply the supplied brand as an adapter

Use when an artifact must follow an existing brand. No vendor palette, font family
or personal aesthetic is a universal default.

1. Read the actual supplied brand brief, approved assets, token files and type rules.
   Record the source and version for colors, typography, spacing and logo treatment.
   Separate binding requirements from examples and preferences.
2. Map supplied values to semantic roles rather than scattering literals through
   artifacts. Use color-kit for contrast and palette decisions and ui-ux-kit for
   screen/component behavior. Preserve approved logo geometry and clear space.
3. Check fonts available to the rendering backend. Record a fallback and resulting
   layout differences instead of silently substituting a lookalike. Keep factual
   content intact while applying visual rules.
4. Verify at the actual output size and media: contrast, text hierarchy, clipping,
   alignment, readability and exported assets. A brand reference is not permission
   to copy another product's complete interface or invent official endorsements.
5. Return the mapping, source anchors, preview/export checks and explicit exceptions.
   Unknown brand requirements remain unknown; do not borrow a familiar company's
   colors simply because no brief was supplied.
