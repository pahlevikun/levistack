# Compose from the relationship

Write what the reader should understand after a brief look. Choose a structure that makes that relationship visible even when the headline is covered.

| Relationship | Structure | Meaning to protect |
|---|---|---|
| Comparable values | Aligned bars, dots or small multiples | Shared unit, baseline, period and scale |
| Before and after | Paired views with matching frames | Equal scope and a named delta |
| Inputs reach a bottleneck or decision | Convergence | Direction, finite capacity and the destination |
| Nested scope or responsibility | Containment or layers | Actual inclusion. Do not imply chronology |
| Shared membership | Overlap | Explicit set and intersection definitions |
| Events across time | Timeline with lanes | True dates, intervals and uncertainty |
| Geography | Map with scale and projection context | Actual spatial position. Do not substitute arbitrary layout |
| Defined relations | Network or adjacency view | What nodes, links, direction and distance mean |
| Source-to-claim reasoning | Evidence lanes | Observation, transformation, inference and uncertainty |
| Product behavior as proof | Real screenshot with annotations | Authentic state and an honest crop |

Use one dominant structure per graphic. Split a long story into modules or pages when each answers a different question. Empty lanes can show a real absence or unresolved check, but label them so the reader does not mistake decoration for data.

## Set the reading path

Place the subject and bounded claim where the reader enters. Follow with evidence, interpretation and source or method detail. Keep the nearby caveat attached when panels reflow.

Choose a grid for the task:

- A single text column suits a visual essay and method notes.
- Shared columns align comparisons and source ledgers.
- A modular grid supports repeated records or small multiples.
- Time lanes preserve chronological comparison.
- Spatial and network layouts need explicit meanings for position and proximity.

Name why the grid works. It should make comparison, sequence or separation easier. Use margins, direct labels and rules where they carry information. Add a container only when it groups something meaningful.

Keep one dominant visual and a clear type hierarchy. Make evidence text legible before fitting more material. Use the project's fonts and roles. Measure text at the actual delivery size rather than trusting source units alone.

If a style reference helps, borrow a method such as disciplined alignment, clear annotation or repeated comparison. State what transfers and what stays original. Avoid turning a subject into an unrelated retro costume.

## Batch work

Review the batch as thumbnails. Keep the same semantic colors and typography while varying composition for each relationship. For four or more assets, try several structures where the evidence supports them. Repeated comparison charts are valid when comparability is the point. Do not vary truthful scales merely to make every page look different.

Check that each page has a useful takeaway, each essential caveat remains attached, and readers can follow the page order. A carousel should still be understandable when one panel is shared separately.
