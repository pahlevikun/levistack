# Compose and check artwork

Start from a one-sentence intent, not a predetermined palette or template. Define
what the viewer should notice first, then the supporting rhythm. Sketch hierarchy,
negative space, alignment, typography and any motion before polishing details.

For canvas work, use actual dimensions, edge margins and a clear focal point.
Text is an intentional element: readable, correct and placed in its own editable
shape where possible. Preserve uploaded assets and list any transforms. A change
to an existing artifact should honor its requested content and established brand.

For procedural work, separate seed from style parameters and geometry. The same
inputs must rebuild the same source. Explore several seeds intentionally; pick
by the brief rather than treating randomness as quality. The bundled circle-field
recipe is a working starting point, not the only permitted visual algorithm.

For animation, define the motion's purpose and target loop before encoding. Keep
frames consistent in geometry and palette. Avoid rapid high-contrast flashes,
long idle sections and unreadable text. Use the target platform's current file
limits when supplied; do not hardcode one service's constraints as universal.

Inspect the exported result rather than the source alone. Check edges, clipping,
legibility, font substitution, transparent backgrounds, color intent and alternate
static output. Structural checks do not prove aesthetic quality. If no renderer
or viewer is available, deliver the editable artifact and state inspection pending.
