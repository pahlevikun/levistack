# Provenance and selected adaptations

This package consolidates the prior Eave/Tabshelf conversation workflow and selected reusable guidance from the sources below. Names are attribution and maintenance history, not required skills or runtime calls. The local procedures contain the operational instructions. Original source packages remain separate and untouched.

The detailed conversation lessons are embedded rather than kept as execution history: editor-session identity after Cancel/reopen, A → B → A, complete recovery text, actual pointer media checks, valid native captures, real extension APIs, settled contrast samples, forced-color probes and production source/asset provenance. Optional project references are examples requiring current-source confirmation.

This is a selected synthesis for existing-product refinement, not a lossless archive of every source principle or catalog. Unrelated source modes, setup commands and heavyweight tools were omitted because they do not serve that job or would reintroduce an external dependency. The adaptation was updated on 2026-10-25. No source artwork, templates or executable implementation was copied.
