# Directions for look variants

A look prototype fails when its variants are the same design in different paint. Give every variant a **direction** before you draw it. A direction is a short idea about how the screen should feel and how it is built.

## Write one per variant

Use this record. Keep it to five lines.

```
Name: <one or two words, like "Quiet Ledger" or "Loud Shelf">
Idea: <one sentence: what this screen believes>
Structure: <layout, hierarchy, the main thing the eye hits first>
Type and shape: <number face, label voice, corner radius, rule style>
Text rule: <how much text, and where it sits>
```

Rules for the record:

- The name must be a real handle. If two names could swap places, the variants are too close.
- The idea says what the screen **believes** ("money is calm", "every row is a decision"). It never names a color.
- The structure line must differ from every other variant. Different first thing the eye hits, different grouping, different main action.
- Keep the records free of the product's topic. A direction should still make sense on another screen. That is what lets you carry the winner onto the next one.

## Pick directions that can disagree

Start from tensions, then give each variant one side:

| Tension | One side | Other side |
|---|---|---|
| Density | Dense, many rows, small type | Sparse, one thing at a time |
| Weight | Big numbers, tiny labels | Even sizes, label-led |
| Space | Cards with edges | Open rows with rules |
| Control | Everything visible | Progressive, hidden until needed |
| Voice | Plain and official | Warm and personal |

Choose the tensions that match the question. Do not use all of them.

## Quiet reference

A screen can carry a small nod to its subject without saying it. A budget screen can borrow the look of a ledger line. A travel screen can borrow a boarding pass. Use it in one place: a rule style, a number face, a stamp shape. If a viewer has to be told, it is too faint. If every viewer notices at once, it is too loud. Never copy a real brand or a real artist's work.

## Text is a visual part

- Show information through grouping, size and position first. Add words second.
- A label is short. A sentence on a prototype screen needs a reason.
- Keep every element inside its frame with a visible margin. Nothing touches the edge. Nothing overlaps.

## Finish by refining

After the first render, do **not** add more. Fix what is already there:

1. Align the edges that almost line up.
2. Tighten the spacing steps to a short list (for example 4, 8, 16, 24).
3. Remove one element from each variant and see if it still answers the question.
4. Make the focal point clearer by reducing the others, not by growing it.

If the urge is to add a new shape or effect, ask instead: how can what is already here look more deliberate?
