# Parking Lot

Tangents are fine. Chasing them mid-task is how the original task never gets finished.

## Procedure
1. Name the current task out loud in one line, so you know what you are returning to.
2. Append the tangent to `PARKING_LOT.md` (create it if missing) as one line: date, idea, why it might matter.
3. Do not research or start the tangent. Capturing it is the whole job.
4. Return to the current task and continue from the last step you finished.
5. At a natural break, read the parking lot and decide for each item: do it, schedule it, or delete it.

## Pitfalls
- A tangent that blocks the current task is not a tangent. Say so and handle it now.
- Keep entries to one line. A long entry is a new task in disguise.
