# One Next Action

When everything feels equally urgent, pick one physical action and start it.

## Procedure
1. Ask for the goal in one sentence. If it takes more, it is two goals: pick one.
2. Name the smallest action that moves it forward and takes under 25 minutes. It must start with a verb and be doable right now ("Open the file and write the failing test", not "work on auth").
3. Name what "done for this round" looks like, so there is a finish line.
4. Start a 25-minute timer. Do only that action.
5. When time is up, decide: continue, switch, or stop. Write the next action down before leaving.

## Pitfalls
- If the action is still vague, shrink it again. Opening the file counts.
- Do not plan the whole project. Plan one step.
